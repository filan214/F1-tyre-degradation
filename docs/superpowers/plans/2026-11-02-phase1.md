# Phase 1: one-race exploration implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Track verification below.

**Goal:** Load one training race, verify dry/no-red-flag eligibility, attach past weather, audit C1–C10 cleaning, and save three exploration figures.

**Architecture:** Keep loading/weather in `data.py`, ordered rules and sanity checks in `cleaning.py`, and figures in `plots.py`. The numbered script coordinates these functions and records measured outputs in the experiment log.

**Tech stack:** Existing pinned FastF1, pandas, matplotlib, pytest; no new dependencies.

**Spec:** `PRD.md`, `IMPLEMENTATION_GUIDE.md` §§3–4, 10 Phase 1, 11, and `CLAUDE.md`.

## Global constraints

- PowerShell commands are single-line. Package code uses logging, public functions have annotations and docstrings, and paths derive from config.
- Load laps with `telemetry=False`, `weather=True`, and `messages=True`; verify required columns before using them.
- Weather joins use `LapStartTime`, backward only. Preserve original lap numbers, stints, indexes, and input frames.
- Apply C1–C10 in order; C10 uses the median after C1–C9 within each race.
- The exploration CLI accepts only `TRAIN_YEARS`; never load the 2025 test season in this phase.
- Matplotlib exports use 150 dpi, units, titles, and source notes. Synthetic test figures are explicitly labelled and saved only under tmp_path.
- No model, feature, manifest, baseline, or later-script implementation.

## Review focus

- Missing required FastF1 columns must name the columns and stop.
- Unsorted/duplicate lap indexes and missing lap start times must preserve row correspondence in the weather join.
- Overlapping cleaning failures must count only the first rule, with no input mutation or renumbering.
- Wet/red-flag/unverifiable sessions and empty clean data must not produce apparently valid exploration outputs.
- Failure before downloading real data must be logged without inventing an audit or publishing synthetic figures as race results.
