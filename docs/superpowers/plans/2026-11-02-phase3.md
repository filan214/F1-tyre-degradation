## Constraints and decisions

- Preserve every §6 column and the exact NUMERIC_FEATURES, CATEGORICAL_FEATURES and TARGET lists; lag4/lag5 and current lap time never enter X.
- Input is the saved Phase 2 clean frame. Record the clean-current-lap criterion as a precondition (zero additional removals), then first-match drops for fewer than three prior clean laps, nonconsecutive lap numbers, and a stint mismatch. Log before/after/drop counts per split. Do not rerun target-dependent cleaning inside feature construction.
- Sort inside race/driver, preserve original lap/stint numbers, reject duplicate identities and missing/invalid required source fields. Empty or insufficient history returns a valid empty feature frame and audit.
- Each optional lag requires its entire intervening clean history to be consecutive and in the current stint; missing optional history remains NaN.
- Stint count and OLS slope use all strictly earlier clean laps in the same race/driver/stint, including earlier clean laps before a gap. Use shifted cumulative statistics, never the current target or future laps.
- Infer fixed train/test labels from configured years; reject conflicting supplied labels. The user authorizes identical fixed Phase 3 transformation and row counts for both splits; no test target analysis, tuning, feature selection or model metrics.
- Add --part choices all/clean/features (default all) to script 03; retain run_dataset() as part A for compatibility. --part features reuses existing laps_clean.parquet.
- Fig05 filters configured training years and validates split labels; title/caption explicitly say associative, not causal. Preserve compound colours and 150 dpi.
- No Git metadata exists in this workspace; no worktree, commits or dependency changes are needed.
